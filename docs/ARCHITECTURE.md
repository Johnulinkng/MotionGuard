# 运行逻辑

## 正常真实路径

1. 用户提交原始目标、允许的资料源、预算和授权期限。外部资料读取前，由宿主生成可见的 ResourcePlan。
2. 用户核对清单，按准确 planHash 冻结授权。免费资源的单价与小计为 0、收款地址为 null，不能据此生成收费采购。
3. Agent 进程按冻结计划读取固定 HTTPS 白名单，保留取得时间、内容哈希、原始来源和不可信标记。主机名、目标地址、重定向、响应体大小、JSON 形状与数据时效均受约束。
4. Worker 选择已授权资料。Threat 读取标记为不可信的内容；Consistency 对照原始目标、冻结计划和可信能力目录检查用途。
5. 检查通过后，Worker 再调用真实模型生成带 `[n]` 引用的完整报告。模型或资料失败时保存失败结果，不回填演示报告。
6. 宿主核验引用顺序、报告哈希、来源 hash 与已登记父证据闭包。浏览器通过发布的 TaskResult、证据读取接口和 SSE 展示结果。

在展示任务中，三项资料分别触发 Threat 和 Consistency，共 6 次检查，加上 Worker 选择及报告，共 8 次模型调用。它不是每项任务固定必须达到的调用指标。

## 进程职责

| 域 | 职责 | 边界 |
| --- | --- | --- |
| A：Agent runtime | LangGraph 编排、受限资料读取、模型角色和只读经验检索 | 不继承钱包或 Operator 密钥，无资金账本写入能力 |
| B：公共 API 与策略 | 任务、授权、证据登记、审批、唯一预算账本与幂等 | 不接受模型自报付款成功或扩权 |
| C：Signer | 私有父子 IPC 中的受限签名与结算组件 | 不持有模型上下文，不暴露通用 HTTP 签名入口 |

这些是同一 OS 用户下的进程和能力边界，不等同于容器、文件 ACL 或主机入侵隔离。

## 资料目录

| 来源 | 实际读取 | 限制 |
| --- | --- | --- |
| Base 官方公共 RPC | Base Sepolia chainId 与最新区块 | 测试网，不代表 Ethereum/Base 主网状态 |
| DefiLlama Coins API | ETH/USD 报价和提供方时间戳 | 聚合单点报价，不代表成交价或趋势 |
| DefiLlama chains API | Ethereum/Base TVL | 未提供数据快照时点，只标本机观测时间 |

来源通过固定 route ID 注册，不是浏览器传入任意 URL 的代理。正文和模型最终输出以纯文本显示；不返回隐藏推理或模型密钥。

## 付款和经验

当前真实资料均免费，正常路径不创建 PaymentIntent、模拟收据或链上交易。付款模式仍为 `MOCK`，与 `LIVE_API` 模型和 `LIVE_HTTP` 数据模式独立。

付款内核已有冻结范围检查、精确 REVIEW、BigInt 原子金额、SQLite 幂等账本及独立 signer。未知授权继续占额；撤销只阻止后续动作，不能表述成退款。TESTNET 适配源码保留，但公开 HTTP 入口在真实集成验收前拒绝启动。

真实路径没有可信攻击标签，`learningMode=NO_ONLINE_LABELS`，不自动提炼或晋升经验。Curator 和 oracle 晋升闭环仅在明确标注的沙箱演示中运行。证据哈希能核对完整性与来源绑定，本身不证明外部信息为真或模型判断正确。

## 接口

接口唯一源为 [OpenAPI](../contracts/openapi.json)，当前 HTTP 版本 `0.2.0`。原有对象格式仍为 `schemaVersion=0.1.0`，完整 TaskResult 为 `0.2.0`。

POST 使用幂等键，资源修改使用强 ETag；复核绑定准确付款快照。SSE 携带会话、版本和 Last-Event-ID，断流或刷新不会重跑任务。前端只读重试 `RESULT_NOT_READY`，不自动重放资金操作。
